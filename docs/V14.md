# Compact ZIP downloads — V13 to V16

The ZIP downloads below current and archived setlists use a compact row of ordinary text links. They fit on one line at normal desktop widths and wrap naturally on narrow screens. Each branch retains its existing typography and link colours.

- The shared “ZIP:” label replaces the repeated ZIP badges, bordered cards, secondary lines and disclosure heading. Each link downloads its archive directly.
- Only available archives permitted for the signed-in member appear. Disabled audio/sheet downloads and empty sections remain omitted; no empty download row is shown.
- A section link says “+ Parts” only when its actual archive includes unsplit Parts as a fallback. Its native tooltip and accessible name give the file count, PDF/MP3 format and full Parts explanation.
- Keyboard focus remains visible. The links work without JavaScript, have a 24 px line height on desktop and 28 px on small screens, and are omitted from printouts.
- Existing archive URLs, ZIP creation, cache invalidation and permissions are retained. No data or configuration migration is needed.

The large ZIP cards were introduced in the current V13 line and are replaced consistently in V13–V16. This note's filename retains the older numbering from before the development branches were renumbered.
