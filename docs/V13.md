# NADIN V13

The ZIP links below a gig's setlist now form a compact download grid. Every button shows its section and the actual number of PDF or MP3 files. The whole button downloads the archive in one click.

- Only available archives permitted for the signed-in member are shown. Disabled audio/sheet downloads and empty sections stay hidden; an entirely empty download area is omitted.
- Section archives say “incl. Parts” only when their source list actually contains unsplit Parts as a fallback. A short note explains the meaning.
- The area stays expanded on desktop and collapsible on small screens, with two compact columns on mobile. Keyboard focus is visible, native links and disclosure controls work without JavaScript, and printouts omit the download controls.
- Existing ZIP creation, archive permissions, cache invalidation, onboarding and V12 protection remain unchanged. No data or configuration migration is needed.

Validation uses isolated example data and the existing administration HTTP suite, including section ZIP contents, refreshed source files and access control. No production accounts or files are changed.
