# NADIN 7.7.4 — active download and required-field guidance

Based on the published `v7.7.3` classic release.

The forScore download button stays active. Clicking it with an incomplete selection returns to the first obligatory field, focuses and marks that field, and displays its validation message. The form is not submitted until the missing import option, inventory CSV, PDF choice or missing-note confirmation is supplied. Corrections clear their previous validation message. The optional **Import and updates** help is separated from the download action with a clear gap and a divider.

Automatic section/import/CSV refresh remains available. Clicking download during that short refresh announces that the selection is still being updated. The button and form are not dimmed. Native required-field guidance also works without JavaScript; the manual **Update selection** fallback remains available. Server-side permission, CSRF, stale-preview and export checks are retained.

The correction is applied to both classic lines and V8–V17, preserving each branch's design. Section cookies, PDF identities, annotated-original reuse, headers, repeats, Parts fallback and the installation favicon remain in place. The client script has a versioned URL so the changed behaviour is fetched after updating.

A long setlist verifies the return from the bottom action to the import field near the top. Tests also cover changing away from a missing CSV, correction of errors, real first/update downloads, automatic refresh, JavaScript-disabled use, and the help spacing at 1200, 390 and 320 px.
