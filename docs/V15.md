# NADIN V15

V15 refreshes the existing interface without changing navigation, workflows or permissions. It includes all V14 download improvements and V13 login protection.

- A local system font replaces the external Google Fonts request. Clear navy text, consistent blue links, quiet grey surfaces and warm yellow selection markers retain NADIN's familiar character.
- Header, navigation and toolbars use less vertical space. Tune rows, gig lists and the editing catalog remain compact; decorative empty areas and oversized cards are avoided.
- Gig editing and People & permissions use the same fields, buttons, selection states and focus outlines. Rights groups use less vertical space and sit side by side on phones when there is room, reverting to one column on very narrow screens.
- Login, password forms, forScore and the ZIP area follow the same styling. Mobile action menus remain readable and keyboard focus stays visible. No new setup or extra user decisions are introduced.
- The refresh is CSS plus version labels. Server behaviour, account data, permission dependencies, undo/conflict handling and file formats are unchanged. No migration is required.

Validation uses actual PHP views with synthetic accounts and music, 104 administration HTTP checks, 29 administration DOM checks, 8 login DOM checks, and PHP syntax checks. Local software DOM checks do not replace a live visual check in the production browser; the cloud browser cannot reach this workspace's local preview.
