# NADIN 7.7.3 — guided forScore export

Based on the published `v7.7.2` source. This release improves the forScore page within the original NADIN interface and retains the CSS-based GigRep layout from 7.7.2.

## Musician workflow

- The chosen section is remembered for one year in this browser, separately for each installation and account. The server validates the saved section against current rights. It is shown correctly on the first render and remains changeable.
- Choose one import intent: first NADIN import with PDFs, add to existing notes using a fresh forScore inventory CSV, or setlist only. The first-import confirmation and the inventory are not saved as browser preferences.
- Section, import and CSV changes refresh automatically. The separate Review step is removed from the JavaScript interface; **Update selection** remains available when JavaScript is disabled.
- A single matching PDF is selected automatically and displayed without a dropdown. Multiple candidates or local revisions remain selectable. Missing notes still require explicit placeholder confirmation.
- The summary shows ordered setlist entries, headings, unique PDFs to include or reuse, and any remaining decisions. Repeated tunes retain their positions; their PDF is embedded once.
- **Download forScore setlist (.4ss)** becomes available when the choices are complete. Server-side permissions, CSRF, stale-preview and source-file validation remain in force.
- The standalone page explicitly loads NADIN's own `favicon.ico`, relative to the installation. It no longer inherits the parent site's favicon.

The workflow is backported to both classic branches and V8–V16. Each branch keeps its visual design: classic controls on the older interface, refined controls on V14/V15, and the existing popup frame on V16. The export format, file identities, tune/header handling and account permissions are unchanged.

| --- | --- |
| 7.7.2 | `NADIN-7.7.2-to-7.7.3.zip` |
| 7.7 / 7.7.1 | `NADIN-7.7-to-7.7.3.zip` |
| 7.6 | `NADIN-7.6-to-7.7.3.zip` |
| New installation | Source archive for `v7.7.3` |

Extract the selected update into the NADIN root, preserving its subdirectories. The packages exclude installation configuration and user/music/GigRep data. Keep the existing salt and hidden forScore identity metadata. Reload an already open forScore page after updating. Checksums are supplied in `SHA256SUMS.txt`.
