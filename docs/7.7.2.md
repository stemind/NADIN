# NADIN 7.7.2 — CSS-based classic GigRep layout

Source base: published `v7.7.1` (`ecf735b1d226d6543f1c9bdee01dd231b8c11d68`). This release keeps the original 7.x interface and forScore behaviour and modernises the layout of the current and archived GigRep list.

## Behaviour

- The list position and tune-area offset are rendered before JavaScript. CSS calculates the height when the window changes; the repeated 777 ms layout timer is removed.
- The list has its own element ID. Layout no longer depends on it being the first `h3` in the page.
- `rendergiglistontheleft='yes'` places the list on the left; `no` or an absent setting keeps it above the tunes. The existing default in the example configuration is still `yes`. The configuration file itself is unchanged.
- A configured positive pixel width is used for the list and adjacent content. Invalid/missing widths fall back to 300 px. The original minimum page width and minimum list height in left mode are retained.
- The archive retains its initially closed info panel and working show/hide control. Current/archive permissions, headings, tune sequence, Print/XLS, PDF attachments, forScore and Library access are preserved.
- `abo/zip/donotdeletethisfolder.txt` ensures the required attachment/download directory is included in fresh source downloads.

The automatic section/CSV workflow work on the separate 7.7 development branch is not folded into this CSS-layout maintenance release. The UTF-8 response correction from 7.7.1 is retained. No configuration, member, Rep or PDF data is migrated by applying the patch.

## Installation

- Already using 7.7 or 7.7.1: apply `NADIN-7.7.1-to-7.7.2.zip` at the NADIN root. It replaces the two GigRep views, `login.php`, and `get/forscore.php`, and includes the ZIP-directory marker and instructions.
- Upgrading from 7.6: apply `NADIN-7.6-to-7.7.2.zip` at the NADIN root to add the forScore implementation and the layout changes together.
- New installation: use the complete source archive for `v7.7.2` and follow the existing NADIN setup instructions.

Both update ZIPs exclude installation configuration and user/music/Rep data. The complete source includes the example configuration; preserve your installation's own configuration when updating.

## Executed verification

Real Chromium checks compare 7.7.2 with the released 7.7.1 geometry for current/archive, member/admin, yes/no/missing flag, two list widths and three window sizes. Additional cases run the new layout without JavaScript, resize the window, scroll a long gig list, navigate to another gig and reopen archive info. Existing forScore HTTP and native browser checks are retained. PHP 8.3.6 and PHP 8.5.12 are used, including a forced ISO-8859-1 server default for the exporter.

Run `NADIN_PHP=/path/to/php python tests/forscore-http.py` and `php tests/forscore.php`. To run actual Chromium layout checks, provide Node Playwright and select `NADIN_CHROMIUM`, then run `python tests/gigrep-layout-http.py`; optionally set `NADIN_LAYOUT_BASELINE` to a 7.7.1 checkout. The general contract is `python tests/main-parity-http.py`.

Native iPad import, production mail and a native PHP 9 runtime are outside these fixture checks. See [the final audit](EVOLUTION-AUDIT.md) for exact executed results and the wider branch review.
