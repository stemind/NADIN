# NADIN — NADIN 7.7.2 — classic GigRep layout

The conservative maintenance release: CSS-based current/archive GigRep layout, the existing yes/no configuration behaviour, explicit UTF-8 forScore output inherited from 7.7.1, and the required ZIP-directory marker.

**Branch:** `7.7.2-css-gigrep-layout`  
**Starting point:** 7.7.1  
**Status:** Conservative published maintenance line, based directly on tag `v7.7.1`.

## Project

NADIN is a file-based PHP application for big bands. It manages sheet music, recordings, member permissions and current/archived gig setlists without a database. It was developed by Urs Petermann and Stefan Minder for the Uptown Big Band Bern. Any warranty and liability is excluded. Project information: https://yuba.ch/nadin.
